# Satvik Way

Wholesale tempeh cubes for **Rishikesh cafe kitchens**. Satvik Way is a supplier, not a cafe. Orders go to WhatsApp — no cart, no Stripe.

## Shop

- Soy Tempeh Cubes (`/collection/classic-soy-tempeh`)
- Cafe Lot Tempeh Cubes (`/collection/cafe-tempeh-lot`) — rate on WhatsApp

Chickpea or mung ferments are not shop SKUs. Ask the Supply Lead that week.

## Local preview

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
